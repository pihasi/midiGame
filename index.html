📖 使い方

基本の流れ

  • 一番上の選択欄からMIDI・SPC・JSON・ZIP・txtをまとめて選べます（複数選択可）。SPC/JSONはMIDIと同じファイル名（設定タグを除く）のものが自動で紐づきます。ファイルの代わりに右のラジオボタンでサンプルパターン（8ビート/16ビート/四つ打ち、いずれもベース音付き）を選ぶこともできます。
  • MIDIが既に読み込み済みの状態でtxtだけ、あるいはSPC/JSONだけを選ぶと、今読み込んでいる曲に対する追加・上書き適用として扱われます。
  • ▶再生／■停止、またはMIDI機器・タップパッド・キーボードの長押しで再生を開始／停止できます（長押しの秒数は設定変更可）。短く叩いた場合は再生中でなければ音の確認だけが鳴ります。
  • 「🎼 手本演奏」：ONにするとMIDIの打楽器演奏情報どおりに自動でお手本の音が鳴ります。OFFなら自分が叩いた音だけが鳴ります。ON/OFFに関わらず、MIDI機器・16pad・キーボードいずれの入力も常に判定を受け付けます（旋律パートは常にこの設定と無関係に自動で鳴ります）。
  • 「🥁 開始時カウント」：ONの場合、▶ボタン（メインの再生ボタン、および長押しでの再生開始）を押すたびに、1小節の拍数ぶんの「1、2、3、4」のカウント（スティック音を合成）を挟んでから再生が始まります。この間もスクロール譜面は自然に流れます。小節としてはカウントされず、ループが1周して自動的に先頭に戻る際は鳴りません。「曲を聴きながら割り当てる」の▶ボタンでは常に鳴りません。
  • 旋律パートは、MIDIのピッチベンド・Volume・Pan・Expression・Reverb量も反映して再生されます（ピッチベンドの幅はRPNの設定を読み取ります。Reverbは曲頭の値を1回だけ反映する簡易対応です）。
  • 「🔁 ループ再生 ON/OFF」：全体譜面（下記）で長押し＋ドラッグして指定した範囲を繰り返し再生します。
  • 右上にバージョン番号（例：0.9.yyyymmddhhmm）を表示しています。

楽譜表示（スクロール式）

  • 縦の基準線を通過するタイミングで叩きます。基準線の位置は「⏱長押し・表示位置の設定」で調整できます。
  • PERFECTは印なし／赤＝早い(上にずれて表示)／青＝遅い(下にずれて表示)／灰＝ミス
  • 薄い丸は「前回そのノーツを叩いた時の判定」の参考表示です。
  • L.CymとR.Cymは、曲の打楽器パートにどちらか一方しか存在しない場合、どの場面でも完全に同じもの（同じ音・同じ判定）として扱われます。

全体譜面

  • タップで再生位置移動、長押し＋ドラッグでループ範囲選択。現在位置(青)とループ範囲(黄)は色で区別されます。「曲を聴きながら割り当てる」欄にも同じ操作ができるミニ版があります。
  • 「区切りの小節数」ごとに赤い太線、「改行の小節数」ごとに改行します（同時の場合は赤線は表示しません）。

小節位置の調整とファイル名/txt共有

  • MIDI読み込み時に区切り情報（txt/ファイル名タグ）が見つからなければ、このパネルは自動的に表示状態になります。
  • 「楽譜から基準指定」：楽譜上の音符を2つクリックしてBPMを実測します。
  • 「小節の開始基準を指定」：楽譜上の音符を1つクリックすると、そこをある小節の区切り位置として、前後両方向に同じ長さで区切りを広げます。指定位置より前に音符が無くなったところが自動的に第1小節になります。
  • BPM/開始位置/区切り/音色割当などを調整後、「MIDI信号の入出力」パネル下部の「この曲の設定を文字列としてコピー」でその内容を文字列としてコピーできます。txtファイル（1行＝1曲、ファイル名＋この文字列）に貼り付けるか、MIDIファイル名自体に埋め込んで保存すれば、次回読み込み時に自動で同じ設定が復元されます（打楽器の音色割当・旋律パートの音色割当・基準ピッチ補正も含みます。muteの状態は保存されません）。
  • 読み取り優先順位：txt内の設定 ＞ ZIPファイル名 ＞ MIDIファイル名 ＞ 自動推定。

打楽器パートの音色（表示レーン・SPC音源の割り当て）

  • MIDIと同名のSPCを一緒に選ぶと、ゲーム内で使われていた波形サンプル(BRR形式)を自動で解析・抽出します。SPC内のどのサンプルがどの楽器かは自動判定できないため、試聴して耳で選んで割り当てます（プルダウンで選ぶと即座に反映されます）。サンプル一覧には長さ・SPC RAM上のアドレス(spc2midi-tsuuの「Addr」欄と同じ値)・既に割り当て済みのパート名を表示します。
  • spc2midi-tsuuというツールでSPCからMIDIを生成すると、ドラムの各サンプルに名前を付けられます（Option内の「Split Drum Notes Into Separate Tracks」を有効にしてエクスポートすると、サンプルごとにトラックが分かれ、下記の略称どおりに名前を付けることで、このアプリ側で自動的に正しい打楽器パートへ割り当てられます）。
  • 打楽器パートの命名規則（大文字小文字は区別しません。表示名そのもの（HiHat等）で入力しても認識されます）：
    • k / kick / bd / b：キック
    • s / snare / sn：スネア
    • h / hihat / hh / ch：クローズハイハット
    • oh / o.hat：オープンハイハット
    • hp / pedal / hhped / l.ped：レフトペダル（ハイハットのフット操作）
    • ht / hitom：ハイタム
    • lt / lowtom / lotom：ロータム
    • ft / floortom / f.tom：フロアタム
    • lc / lcym / l.cym：レフトシンバル
    • rc / rcym / r.cym：ライトシンバル
    • rd / ride：ライドシンバル
    • c / cc / crash / cymbal：左右区別なしのシンバル
  • 空欄または名前が辞書に無い場合は自動割り当てされず、このパネルで手動指定します。同じ名前が複数のサンプルに付いている場合、楽譜上は同じレーンとして表示されますが、実際に鳴る音は各ノーツに元々紐づく個別のサンプルがそのまま使われます。表示レーンを変更しても、割り当てたSPCサンプルは音色名にひもづいたままついてきます。
  • JSON内のキー番号(SRCN)がこのアプリの抽出サンプル番号と同じ方式のため、名前(k/s/h/c等)が略称辞書に一致するものは自動でSPCサンプルが割り当てられます。
  • 「→旋律として扱う」：実は打楽器ではなかった音色を旋律パート側に移せます（曲読込直後・未再生時のみ操作可）。

旋律パートへの割り当て

  • 1チャンネル＝1音源という前提で、各MIDIチャンネルに使うSPCサンプルを選べます。（）内は実際に割り当てたサンプルのJSON上のinstrument_nameで、未割当のチャンネルには表示されません。
  • JSONのChannel Routingが明示的に変更されている（曲の途中で音色が入れ替わる等）場合、対応するMIDIチャンネルへSPCサンプルが自動で割り当てられます。またJSONのcenter_note情報から、割り当てたサンプルの基準ピッチも自動推定されます（ズレる場合は「基準ピッチ補正」欄で手動調整できます。正の値でピッチが上がります）。
  • mute（チェックボックス）/solo（ボタン、押すと自分だけmute解除・他は全部mute）は、旋律パートの発音そのものに効きます（▶再生・「曲を聴きながら割り当てる」の▶再生どちらでも共通）。打楽器の判定には影響しません。「全部on」で一括解除できます。
  • 「→打楽器として扱う」：実は打楽器だったチャンネルを打楽器パート側に移せます（曲読込直後・未再生時のみ操作可）。

曲を聴きながら割り当てる

  • 音色割当パネルの下部にある、ミニ版の全体譜面＋▶再生／■停止／🔁ループ再生です。割当作業をしながら、その場で曲を聴いて確認できます。ここでの再生には開始時カウントは入りません。

キーボード操作

  • 1,2,3,4 / Q,W,E,R / A,S,D,F / Z,X,C,V が16パッドに対応します（パッド上に表示）。
